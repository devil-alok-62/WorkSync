# 📊 SaaS Analytics Dashboard (Next.js + MongoDB + Recharts)

A modern, production-ready **real-time analytics dashboard** built with Next.js, MongoDB, and shadcn/ui.  
It provides live insights for tasks, teams, and activities with a scalable SaaS architecture.

---

## 🚀 Features

- 📊 Real-time Analytics Dashboard
- 🧠 MongoDB-based dynamic data system
- 📌 Task management (Pending, In Progress, Completed, Review)
- 👥 Team management system
- 📈 Interactive charts using Recharts
- 🎨 Modern UI with shadcn/ui + TailwindCSS
- ⚡ API-driven architecture (Next.js App Router)
- 🔄 Ready for Socket.io real-time updates
- 📱 Fully responsive design

---

## 🏗️ Tech Stack

- Next.js (App Router)
- TypeScript
- MongoDB + Mongoose
- Tailwind CSS
- shadcn/ui
- Recharts
- Socket.io (optional real-time layer)
